# Moon Lab

这是一个用于学习现代 Web 开发流程的实验项目。

## 项目简介

本项目使用 React + Vite 创建，用于学习和实践现代前端开发的基本工作流程。

目前已经完成：

- Node.js 环境搭建
- npm 包管理
- React 项目创建
- Vite 开发与构建
- `npm run dev` 开发模式
- `npm run build` 生产构建
- `npm run preview` 构建结果预览
- Git 版本管理
- GitHub 远程仓库
- SSH Key 身份认证
- Git 推送到 GitHub

## 技术栈

- React
- Vite
- Node.js
- npm
- Git
- GitHub

## 常用命令

```bash
# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建结果
npm run preview

# 查看 Git 状态
git status

# 提交修改
git add .
git commit -m "说明"

# 推送到 GitHub
git push
